# Product Management MVC

Ứng dụng quản lý sản phẩm bằng Servlet, JSP, JSTL và kiến trúc MVC. Có chức năng hiển thị, thêm, sửa, xóa, xem chi tiết và tìm kiếm sản phẩm theo tên.

Dữ liệu được lưu bằng Map tĩnh để mô phỏng cơ sở dữ liệu. Chạy `mvn clean package`, deploy `target/product-management.war` lên Tomcat 10.1+ và truy cập `/product-management/products`.
